# Accessibility Defect Log (WCAG 2.2)

## 📌 Overview

This repository contains a sample accessibility defect log created as part of accessibility testing for a web application.

## 🎯 Objective

To identify and document accessibility issues based on WCAG 2.2 Level A & AA guidelines.

## 🛠️ Testing Coverage

* Keyboard Accessibility
* Screen Reader Testing (NVDA)
* Color Contrast Validation
* Focus Management
* ARIA Roles and Labels

## 📊 Defect Log Details

The attached Excel file includes:

* Issue description
* WCAG success criteria mapping
* Severity level (High/Medium/Low)
* Steps to reproduce
* Expected vs actual behavior
* Recommended fixes

## 🔍 Sample Issues Covered

* Missing accessible names for buttons (WCAG 4.1.2)
* Improper focus order (WCAG 2.4.3)
* Low color contrast (WCAG 1.4.3)
* Keyboard navigation issues
